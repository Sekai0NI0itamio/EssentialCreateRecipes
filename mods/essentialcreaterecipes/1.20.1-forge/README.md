# Essential Create Recipes

A Minecraft mod (Forge 1.20.1) that combines the best Create recipe and automation addons into one mod.

## What it does

Adds Create processing recipes (mixing, crushing, compacting, pressing, milling, cutting, filling) to automate items that are normally non-renewable or tedious, inspired by:

- Create: Automate Everything
- Create: Full Automation
- Create: Recipe Extensions
- Create: Ultimate Factory
- Create: Refabricated Recipes

## Recipes included (v1.0.0)

- Crimsite (mixing, heated)
- Veridium (mixing, heated)
- Ochrum (mixing, heated)
- Asurine (mixing, superheated)
- Tuff (mixing, heated)
- Cobbled Deepslate (compacting)
- Dripstone Block (compacting)
- Pointed Dripstone (cutting)
- Magma Cream (milling)
- Basalt Crushing (crushing -> blackstone + lapis)
- Snow -> Ice (compacting)
- Brass Ingot (mixing, heated)
- Netherrack (mixing, heated)
- Ink Sac (filling, requires Create: Enchantment Industry)

## Requirements

- Minecraft 1.20.1
- Forge 47.4.20+
- Create 0.5.1+
